# internship-finder

## User inputs
The user provides information about the internship they are seeking, including:
- Desired roles or career fields
- Preferred industries and companies
- Location preferences and willingness to work remotely or relocate
- Academic major, graduation date, skills, and relevant experience
- Internship term, such as summer or fall
- Application deadlines
- Available time for searching, networking, and applying
- Resume, cover letter, portfolio, LinkedIn profile, or job postings when available
If an essential detail is missing, the AI agent should ask for the user’s target role, preferred location, internship term, application deadline, and current application materials. It should ask only for information necessary to complete the current request.
